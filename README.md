# Vehicle Rental System 🚗🏍️

A simple **Vehicle Rental System** built using **Python** and **Object-Oriented Programming (OOP)** concepts.
This project allows customers to:

* View available vehicles
* Rent vehicles for a specific number of days
* Calculate rent automatically
* Return rented vehicles

---

# ✨ Features

* Add Cars and Bikes to the rental system
* Show available vehicles
* Rent a vehicle
* Return a rented vehicle
* Automatic rent calculation
* Discount system:

  * **Cars:** 10% discount for rentals more than 5 days
  * **Bikes:** 5% discount for rentals more than 3 days
* Beginner-friendly Python project

---

# 🛠️ Technologies Used

* Python
* Object-Oriented Programming (OOP)

---

